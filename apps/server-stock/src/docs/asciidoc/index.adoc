== 4. 주식 호가 (OrderBook)

=== 4-1. 실시간 호가 스냅샷 단건 조회
종목 상세 페이지 최초 진입 시, 화면의 빈 공간(스켈레톤 UI 등)을 즉시 채우기 위해 인메모리 캐시에 저장된 최신 1~10호가 스냅샷을 조회합니다.
(조회 이후 실시간 데이터 업데이트는 STOMP 웹소켓 채널 구독을 이용해주세요.)
